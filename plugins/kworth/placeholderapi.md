# PlaceholderAPI

## PlaceholderAPI

KWorth hỗ trợ PlaceholderAPI khi PlaceholderAPI đã được cài trên máy chủ.

### Placeholder chung

```
%kworth_currency%
%kworth_style%
%kworth_confirm%
```

### Placeholder category và item

```
%kworth_sold_<CATEGORY>%
%kworth_multiplier_<CATEGORY>%
%kworth_next_required_<CATEGORY>%
%kworth_category%
%kworth_price%
%kworth_base_price%
%kworth_price_raw%
%kworth_base_price_raw%
%kworth_market%
%kworth_progress%
%kworth_effective%
```

Placeholder chỉ hoạt động khi KWorth và PlaceholderAPI cùng tải thành công.

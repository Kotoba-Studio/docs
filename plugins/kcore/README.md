# KCore

## KCore R01-v9

KCore là gameplay core của hệ sinh thái Kotoba Studio. Plugin hợp nhất tiện ích EcoSMP vào một runtime chung.

### Bao gồm

* Travel: Spawn, Home, Warp, TPA và RTP.
* Player: Settings, Profile, Leaderboards và Vaults.
* Framework: Menu Engine, PlaceholderAPI, Currency Bridge và LuckPerms Policy.
* Protection: KWL, KWB và AntiLagMachine.

### Thông tin build

```
Plugin: KCore
Version: R01-v9
API version: 1.21
Folia supported: true
Main class: com.kotobastudio.kcore.KCorePlugin
```

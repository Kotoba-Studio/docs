# Kotoba Studio

## Kotoba Studio

Tài liệu chính thức dành cho các plugin và sản phẩm được phát triển bởi Kotoba Studio.

Kotoba Studio phát triển công cụ cho máy chủ Minecraft. Mục tiêu rất rõ ràng: dễ cài đặt, dễ cấu hình và ổn định trong môi trường thực tế.

### Thiết kế của Kotoba

**Clean**\
Cấu hình rõ ràng và hạn chế những thành phần không cần thiết.

**Stable**\
Ưu tiên tính ổn định, bảo vệ dữ liệu và khả năng sử dụng thực tế.

**Developer Friendly**\
Tài liệu rõ ràng và hỗ trợ tích hợp khi plugin cung cấp API.
